# Grill Hub Staff (Android native)

Kotlin + Jetpack Compose. CameraX + ML Kit for QR scanning. PIN stored with EncryptedSharedPreferences (Android Keystore).

Open this folder in Android Studio (Koala or newer), let Gradle sync, then Run on a phone or Build > Build APK(s).

API base URL: `Api.baseUrl` in `Api.kt` (default https://grillhub.pl/wp-json/loyalty/v1).
Logo: `app/src/main/res/drawable-nodpi/logo.png` (also the launcher icon).
